# 法律文书类型判定

## 硬性约束（违反即终止）

1. **仅输出判断结果**，不执行任何后续处理
2. **禁止提取**文书中的字段（当事人、案号、日期等）
3. **禁止匹配**状态机或进行流程推演
4. **禁止修改**任何文件
5. **禁止移动或删除**任何文件
6. **禁止输出**法律建议或分析意见
7. 判断依据**仅基于**下表关键词与格式特征，禁止主观推断

## 需完整 AI 解析的文书类型（9类）

| 序号 | 文书类型 | 识别特征关键词（命中任一即判定） | 典型格式特征 |
|------|----------|----------------------------------|--------------|
| 1 | 应诉通知书 | "应诉通知"、"应在收到之日起十五日内" | 法院盖章，含案号、答辩期限 |
| 2 | 起诉状/仲裁申请书副本 | "起诉状"、"仲裁申请书"、"诉讼请求" | 含原被告信息、诉讼请求、事实与理由 |
| 3 | 举证通知书 | "举证通知"、"举证期限" | 含举证期限、举证要求 |
| 4 | 开庭传票/通知书 | "传票"、"开庭通知"、"改期开庭"、"出庭" | 含开庭时间、地点、审判人员 |
| 5 | 判决书/裁定书/调解书 | "判决书"、"裁定书"、"调解书"、"裁定如下" | 含裁判结果、法律依据 |
| 6 | 上诉状副本 | "上诉状"、"上诉于" | 含上诉请求、上诉理由 |
| 7 | 执行通知书 | "执行通知"、"强制执行" | 含执行案号、执行标的 |
| 8 | 执行结案通知 | "执行结案"、"执行完毕" | 含结案方式、执行结果 |
| 9 | 生效证明 | "生效证明"、"已发生法律效力" | 含生效日期、案号 |

### 命中判定规则

- **"命中"定义**：文书正文中出现关键词的**完全一致**子串匹配（非模糊匹配、非近义词）
- **单类型命中**：若仅命中一个类型的关键词 -> 直接判定为该类型
- **多类型命中**：若命中多个类型 -> 按命中关键词**数量**降序排列，取数量最多者
- **平局处理**：若多个类型命中数量相同 -> 按上表**序号从小到大**取优先者
- **特殊规则**：序号 6 的"上诉"单独出现**不构成命中**（须出现"上诉状"或"上诉于"），避免与判决书中"上诉于XX法院"混淆

## 仅归档存储的材料（不解析）

### 证据材料

| 类别 | 材料类型 |
|------|----------|
| 合同类 | 劳动合同、劳务合同、承揽合同、保密协议、竞业限制协议 |
| 财务类 | 银行流水、工资发放记录、社保缴纳记录、公积金记录 |
| 证明类 | 工伤认定书、劳动能力鉴定书、考勤记录 |
| 其他 | 聊天记录截图、邮件往来、工作成果文件 |

### 程序性附件

| 材料类型 | 说明 |
|----------|------|
| 送达地址确认书 | 当事人确认送达地址 |
| 风险告知书 | 法院/仲裁委的风险告知 |
| 授权委托书 | 律师/代理人授权 |
| 法定代表人身份证明 | 法人身份信息 |
| 证据清单 | 证据目录（与证据材料区分：此处为清单文件本身） |

## 判断流程（严格按顺序执行）

1. 扫描文书全文，对 9 类文书关键词逐类型进行子串匹配，统计每类命中数量
2. 若有类型命中（命中数 ≥ 1）-> 按多类型命中规则确定最终类型 -> 标记"需完整解析"
3. 若 9 类均未命中 -> 检查是否属于证据材料或程序性附件范围 -> 若属于，标记"仅归档存储，不解析"
4. 若以上均不匹配 -> 标记"未知类型"
5. **停止**，输出结果，不执行任何后续操作

## 输出格式（严格按此格式输出，不要添加额外说明）

```json
{
  "文书类型": "<类型名称 或 证据材料/程序性附件具体类型 或 未知类型>",
  "是否需解析": "<是 | 否>",
  "判定依据": "<命中的关键词列表 或 匹配的材料类别 或 未匹配任何类型>"
}
```

### 输出示例

9类文书命中：
```json
{
  "文书类型": "判决书/裁定书/调解书",
  "是否需解析": "是",
  "判定依据": "命中关键词：判决书、裁定如下"
}
```

证据材料：

```json
  "是否需解析": "否",

}
```

未知类型：
```json
{
  "文书类型": "未知类型",
  "是否需解析": "否",
  "判定依据": "未匹配任何已知类型"
}
```
