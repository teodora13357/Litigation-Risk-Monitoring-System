# 按人名/案件号整理当前文件夹中的文件

## 硬性禁令（违反即终止）

1. **禁止删除**任何文件或文件夹
2. **禁止重命名**任何文件或文件夹
3. **禁止修改**任何文件内容（包括但不限于读取后写入、追加、覆盖）
4. **禁止移动**子文件夹内的文件——仅处理当前文件夹根层级的文件
5. **禁止处理**隐藏文件（以 `.` 开头的文件）
6. **禁止处理**目录——仅处理文件
7. **禁止递归**进入子文件夹扫描

## 标识识别规则

### 优先级：案件号 > 人名

当文件名中同时包含案件号和人名时，**以案件号为准**，归入案件号文件夹。

### 案件号识别

标准案号正则（严格匹配，大小写敏感）：

```
\((\d{4})\)([\u4e00-\u9fa5]+\d+)([\u4e00-\u9fa5]+\w*)(\d+)号
```

匹配示例：
- `(2024)粤0106民初1234号` → 年份2024 / 法院粤0106 / 类型民初 / 序号1234
- `(2024)粤0106劳人仲案123号` → 年份2024 / 仲裁委粤0106 / 类型劳人仲案 / 序号123
- `(2023)京0108执5678号` → 年份2023 / 法院京0108 / 类型执 / 序号5678

**文件夹命名规则**：使用案件号**完整原文**作为文件夹名（如 `(2024)粤0106民初1234号`），不做任何截断或改写。

### 人名识别

当文件名中**未命中**案件号正则时，才尝试识别人名。

人名识别条件（须同时满足）：
1. 文件名中存在 2–4 个连续汉字
2. 该汉字序列**不构成**案件号的一部分
3. 该汉字序列**不是**通用词（如"通知书""判决书""调解书""起诉状""传票""裁定书""上诉状""执行通知""结案通知""生效证明"等文书类型词）

**冲突处理**：若文件名中存在多个候选人名，取**最长**的连续汉字序列；若长度相同，取**最先出现**的。

**文件夹命名规则**：使用人名原文作为文件夹名。

## 执行步骤

1. **扫描**：列出当前文件夹根层级的所有条目，区分文件与文件夹
2. **过滤**：排除子文件夹、隐藏文件、目录
3. **识别**：对每个剩余文件，按"案件号 > 人名"优先级提取标识
4. **归类**：
   - 若标识命中已有文件夹名（**完全一致**，不可部分匹配）→ 移入该文件夹
   - 若标识未命中任何已有文件夹名 → 新建以标识命名的文件夹，移入文件
   - 若无法提取任何标识 → **保持原位不动**，记录到未归类列表
5. **移动**：使用 `mv` 命令逐个移动文件，每次移动后验证目标文件存在

## 输出格式（严格按此格式输出，不要添加额外说明）

```
## 已归类

### [文件夹名]（新建/已有）
- [文件名]

### [文件夹名]（新建/已有）
- [文件名]

## 未归类（保持原位）
- [文件名]

## 统计
- 已处理文件：N 个
- 新建文件夹：M 个
- 未归类文件：K 个
```

若无未归类文件，输出 `## 未归类（保持原位）\n无`。
